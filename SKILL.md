# Evidence Filter

1. **Define the question.** Identify what must be explained or verified. Separate direct observations from interpretations.
2. **Name the plausible explanations.** Include an unknown cause if the list is incomplete. For each serious candidate, identify an observation that would count against it under the present conditions.
3. **Test the difference.** Prefer a check whose possible results distinguish the candidates. Rule out a candidate only when reliable evidence contradicts a necessary prediction and the check's prerequisites hold. A missing observation with an unreliable check leaves the candidate open.
4. **State what survives.** Say what the evidence supports, what it rules out, and what remains open. A surviving candidate is provisional unless the candidate set is exhaustive or independent evidence establishes it.
5. **Stop when the decision is supported.** If the evidence cannot distinguish the remaining candidates, state the uncertainty and the next useful check. Keep the explanation proportional to the task.

Example: A lighting app previews blue while the physical keyboard stays in its old mode. This rules out the claim that the keyboard is already displaying blue. It leaves several causes open, including an unsent command and a command the device rejected. Check whether the device received the lighting command before naming a cause.
